# Data Structures in C
This repository contains C programs for the Data Structures Laboratory.

## Programs
Program 1 : Generate all possible permutations of given list of symbols as values.

Program 2 : Write a C program to generate a magic square of odd order n using the Siamese method. 

Program 3 : Write a C program to generate a magic square of even order n using the Siamese method. 

Program 4 : Check whether the given string is a palindrome or not by using stack and queue.

Program 5 : Check whether the given string is in the form w.wrev or not by using stack
